## 6. Traps for a Go port

- **Async contract** (`docs/extension-authoring.md` "Async behavior", "Awaited handler"): each inbound handler runs on its own goroutine; **block inside the handler** to preserve `await`. Do not `go func(){…}()` and return nil: that changes ordering, drops errors, and cancels the handler-scoped `sdk.Context` when the handler returns (:55-62). Fire-and-forget needs an owner with independent cancellation, error reporting, shutdown drain (:94-103). `Context` captured after a handler returns is a "retained Context": cancelled origins never become unparented live calls (`api-parity.md:~54`).
- **Host-call lifetime/liveness**: SDK answers `ping` itself; requests report `started/progress/blocked:*/completed`; awaited host calls report `blocked:host_call` and the host may cancel via heartbeat (`extension-authoring.md` "Subprocess request liveness", `api-parity.md:65`). `ctx.Done()` = request; `ctx.Signal()` = run (nil while idle: a `session_start` handler runs idle, so `Signal()` is nil there).
- **Events during `agent_settled`**: handlers may call host methods (settle-tail handlers are awaited; Go has no microtask limitation: "A runtime with no microtask continuation (Go, Rust and Python SDKs) reports no…" `api-parity.md:152`). Run-starting actions (`sendMessage` with `triggerTurn:true`, prompts) issued there **wait until every settled handler returns** (`api-parity.md:165`). In RPC mode stdin is gated from `agent_end` until `agent_settled` is written (`api-parity.md:152`, `rpcSettleGate`). `turn_end` is awaited before the Agent chooses its next turn and can return `entries`/`continue` (`api-parity.md:167`).
- **`context` handler**: mutate `data["messages"].([]any)` in place or return `map[string]any{"messages": []any{…}}` (or `[]map[string]any`). Unchanged list (same map identities, in-place field edits) keeps system boundaries; reorder or equal-valued fresh messages count as replacement; `messages: nil` or no result = keep in-place edits; a non-list `messages` is a handler error (`extensions/sdk/context_event.go:12-80`, `api-parity.md:168`). Handlers see messages without system messages; `context_with_system` includes them. Large lists traverse a 128 MiB frame cap.
- **`tool_result` replacement**: return `map[string]any{"content": []any{map[string]any{"type":"text","text":"…"}}}`; omit `details` (host JSON tag `omitempty`, so absent = keep) and `isError` (nil = unchanged). Patches chain in load order across handlers (`events.go:987-1006`, `api-parity.md:229`). Event `content` arrives as `[]any` of blocks; `event.input` is in the model's key order.
- **`compact`**: use `CompactWithOptions` for callbacks; `Compact(map)` fires and forgets. Callbacks run off-handler on a goroutine started with `awaitCompletion:true`; compaction itself is a Session task not awaited by the call (`api-parity.md:373`, `context.go:1895-1935`). Without callbacks the outcome is dropped silently. `session_before_compact` can cancel/replace via return.
- **`sendMessage` `triggerTurn`**: pointer semantics above; `DeliverAs` ∈ `steer|followUp|nextTurn`; while a turn streams an omitted `triggerTurn` steers, `false` defers (`context.go:488-500`, `README.md:55`). Returns an error from the host.
- **`appendEntry`** data: `any`, JSON-serialized, persisted through reload (`api-parity.md:246`); read back through `GetBranch` (lazy paged load; first call reads the session JSONL, then subscribes).
- **Event ordering for `tool_call`/parallel batches**: Go handlers start in source order, but a preempted goroutine can still be overtaken (`api-parity.md:325`).
- **Tools**: one registration replaces by name; registering in `session_start` calls `registerTool` on a live connection which refreshes the session before returning (`tool_definition.go:89-91`). Registering during `session_start` is supported; but `Tool`/`RegisterTool` before `Run` is the declarative path (`extension.go:490`). Schema validated (`validateToolSchema`); invalid → panic.
- **`ModelRegistry.Find` / `Complete` return untyped maps, swallow decode errors** (`Find` returns nil on error). `Context.Complete` returns raw JSON. Cost lives in flat `*CostPer1M` fields of `ModelInfo`.
- `ctx.Abort()`, `Notify`, `SetStatus` return no error. `Notify` levels are strings.
- `PromptSnippet` partial (see Q2) — an `update_plan`/`obs_recall` snippet may not reach the system prompt.
- Headless/RPC no-op UI: `Notify`/`SetStatus` safe but invisible; guard on `ctx.Mode()` (`context.go:1760`, "tui|rpc|json|print").
- Divergences to read before porting: `docs/parity/DIVERGENCES.md` (D19 SDK bridges, D20 packed cells, D2 shared/separate dirs, D73 Node shims). I did not enumerate which D-numbers touch each listed surface.
